## Checked and held

These tests added since `12c25524` did have a way to fail.

- `tests/lane-costs.test.js`: makes chooseRoute skip codex when its lane-costs reading is above quotaSkipPercent. It passes real quotas into `chooseRoute`, and codex is the first small-tier entry, so a broken `providerOver` returns codex and fails the test.
- `tests/lane-costs.test.js`: fills the newest reading per provider and leaves out a window past its reset. It builds the records itself and asserts a literal window list, so dropping the reset filter or the newest-wins rule fails it.
- `tests/quota-read.test.js`: writes only the newest rollout reading under a temporary CODEX_HOME. It starts the real `startLane` with a fake harness command and reads the record from `runs.jsonl`, so the whole path is run.
- `tests/codex-harness.test.js`: reads the primary and secondary windows from a token_count line. It asserts a literal `resetsAt` built from the epoch seconds, so a wrong unit fails.
- `tests/run-failover.test.js`: refuses a backup whose worktree is the main checkout. It asserts the exact refusal line, the branch and an empty status, so removing the check fails it.
- `tests/mr-agent.test.js`: fails after two reasoning-only replies following a tool error. It counts the API calls and asserts the exit code and the result line.
- `tests/conversation.test.js`: masks a key and a home path and gives line entries for a harness it does not read. The key and the user name are built in the test, and both must be gone from the output.
- `tests/project-dispatch.test.js`: starts run-lane through parseRunArgs with --test and the saved command. The P266 fix put a real `parseRunArgs` call behind the runner, so a runner that rejects `--test` now fails the test.

## What this audit did not do

- Did not run the full suite. The house rules reserve it for the orchestrator.
- Did not change a test. The smallest assertions above are proposals, not edits.
- Did not prove the five help tests marked `inferred`. They share one shape, and the two that were proved show the shape passes with a wrong constant.
- Did not check any test by eye in a browser.
