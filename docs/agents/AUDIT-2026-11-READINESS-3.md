# The panels on another project, P197

Read on 2026-11-13 at `f2a54d89`, version 0.1.401. No application code changed. This pass follows the controls in a live room on another project. It keeps the owner's settled room design.

The largest gaps are actions that lose the target the owner chose: Retry can send an old prompt to a different agent, Auto can start a different lane from its confirmation, and a new lane can take a deleted lane's identity. Settings has two actions whose labels hide a replacement. Failed starts and recorded spend also lose useful facts before reaching the panel.

**Probe + Read** means synthetic assertions reproduced the stated behavior and the surrounding code was inspected. UI probes used the repository's test DOM, not a browser. **Read** means the path was traced without executing its write. No real project, subscription turn, credential or owner history was used.
