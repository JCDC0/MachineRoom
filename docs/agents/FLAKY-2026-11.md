## Shared temp root

One of the eleven `tests/git.test.js` runs did not start. Global setup in `tests/helpers/cleanTemp.js` tried to remove the temp folder of a dead process under `%TEMP%\machineroom-tests` and hit EPERM from a lingering handle. The error aborted setup and Vitest printed `No test files found`. Every lane shares that root, so a locked leftover can stop any run.

`cleanTempRoot` now catches a failed delete for each stale folder and leaves it for the next run. This is a test infrastructure fault only. The other ten file runs passed 34 tests each.
