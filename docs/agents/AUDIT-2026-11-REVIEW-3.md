| 4 | Medium | `src/engine/shapes.js:13-17` | `bandForPoint` computes `angle = Math.atan2(z, x)` and maps `(angle / (Math.PI * 2) + 0.5) * total`. ## Merge by merge

- U129: sound with caveats. It addresses the 10 findings from Review 2: error labels and errors show in log and callout (1); cached views key on local inputs and keep stale recent touches out (3); month spend starts at local midnight on the first (4); pointer drift reads rect on scroll (6); callout crowd counts every busy agent (7); AGY parser prunes `calls` on end (8, though it missed `started`, finding 8); failed pills read newest records (9); CONTROL count is a keyboard-reachable button (10); spend click keeps Costs drawer open (11); empty room line hides while any agent works (12).
- U130: sound with two faults. Added playlist discovery and playback. Safe path checking and 500-track limit work as briefed. Finding 1: when Settings closes, `MusicPlayer` unmounts and removes the ended listener, stopping playlist advancement after the first track. Finding 2: `normalizeSettings` drops `music.playlist` on any setting save.
- U131: sound with two faults. Added folder card wave and shape wireframe pulsing with music bands. Finding 3: `beatDetector` allocates arrays every animation frame and evaluates unthrottled bins. Finding 6: `card.danceAt` is never cleared after a beat lift completes.
- U132: sound. Fixed six growth leaks: session recorder compacts with head index without copying arrays on every push (7); event log call labels capped at 2000 (9); pipeline sweeps idle runs after 30 minutes (10); Claude and AGY parsers prune calls on end (11, also fixing `started` in AGY); removed child shapes return to spare list (16); orchestrator chat prunes departed sub state (17).
- U133: sound with one edge case. Added Bloom screen effect via UnrealBloomPass rendered to a transparent layer with screen blend mode. Disposes targets cleanly on turn off. Finding 7: `bloomPixelRatio` reads `window` without an existence check.
- U136: sound. Converted file tunnel and internet beam to screen-space light trails via `Line2` and `LineMaterial`. Tunnel starts on agent shell facing first waypoint, packets ride only the tunnel with 3-point tails and a 30 percent opacity gate. Geometry updates only when points change.
- S36: sound with one leak. Pack-start verifies `run-lane --dry-run` and `mr-agent` from the unpacked package; `claude-sessions.js` caps evicted sessions at 200. Finding 5: `server/opencode-sessions.js` introduced `forgotten` Map for finished sessions without an upper bound or cleanup.
- S37: sound with one efficiency note. Lanes source throttles old log stat polling to 10 seconds; run completions share one `runs.jsonl` read; turn logs read only the last 64 KB; unpins inactive runs after 2 hours; parser index drops retired agents. Finding 9: `trimHistory` does quadratic unpinning passes on every frame.
- S38: sound. Implemented byte-offset reading for `runs.jsonl` via `cachedRunRecords`, shared across runs API, costs, tasks and reviews; resets cleanly when file shrinks or mtime goes backward; Claude session reader caches `.meta.json` files by mtime.
- Orchestrator fixes to `src/ui/sound.js` (`ecb689d`): replaced 30 percent jump check with standard deviation spread over recent levels. Works for soft music, but still runs on every animation frame without throttling to `sampleBins` interval.
- Orchestrator fixes to `src/engine/shapes.js` (`f70658e`): mapped frequency bands by point angle in X-Z plane so line segments stay joined. Finding 4: at `x < 0, z = 0`, opposite zero signs produce bands 0 and 4, tearing vertices apart.
