# Audit of the Direct API keys and the orchestrator wake rules, version 9

Written 2026-10-30 by AGY 3 on the branch `feat/a9-audit-the-direct`, at `f26d2cb` (0.1.401), for brief A9. It reads `server/endpoints.js`, `server/family.js`, `server/harness-models.js`, `scripts/mr-agent.mjs`, `server/orchestrator.js`, `server/runs.js`, `server/orchestrators.js`, and `src/briefs/run.js`. File and line numbers are those of commit `f26d2cb`. The test suite at that commit has 3344 tests in 190 files. The branch was cut from `refs/heads/main` at `f26d2cb`.

The audit before this one is `AUDIT-2026-10-V8.md` (the folder blocks and camera hold). This audit inspects the Direct API endpoints, key slot storage, model discovery, child environment key inheritance, sector boundary enforcement in lane runs, and orchestrator turn wake triggers.

## Severity

- High: lasting harm, key leakage, or unauthorized action on the machine.
- Medium: wrong execution or state, bypass of sector boundaries, or unwanted turn execution that spends funds.
- Low: edge case, inconsistency, or unexpected fallback with no lasting harm.

Y1 is High because an endpoint configured with a preset provider name can specify an arbitrary base URL, causing the bridge and the runner to send that provider's API key to a foreign host. Y2 is Medium because a deleted sub orchestrator with no sector bypasses lane restriction checks and starts any lane. Y3 is Medium because a run identifier containing path traversal segments reads files outside the runs folder and exposes failure text in chat. Y4 is Medium because a lane run completion marks an orchestrator as owning a run and wakes it to start paid turns even when the owner never gave it work. Y5 to Y9 are Low.

## What was checked and found sound

- Quick route origin and confirmation enforcement. `POST /api/endpoints/quick` requires `req.headers.origin` (returns 403 `QUICK_ORIGIN_PROBLEM` when absent) and `body.confirmed === true` (returns 400 `QUICK_CONFIRM_PROBLEM`). `server/index.js` pre-filters origins against `isAllowed`. Tested with requests omitting origin and confirmation.
- Cross-origin redirects with Node.js fetch. Native `fetch` in Node 24 strips the `Authorization` header on cross-origin redirects (tested with local HTTP redirect probe).
- Model id path traversal. Passing `../x/MODEL` as `--model` to `scripts/mr-agent.mjs` splits on `/` to find the endpoint name `'..'`. `readEndpoint` searches `endpoints.json` entries in `runsFolder` without using the name in path resolution; no file outside `runsFolder` is read via model id. Marked unproven as a traversal vector.
- Shell tool environment isolation in `scripts/mr-agent.mjs`. `shellTool` calls `childEnvironment(process.env, cwd)` without a `harness` parameter, which strips `OPENROUTER_API_KEY`, `MACHINEROOM_API_KEY`, and `ANTHROPIC_API_KEY` from commands executed by the agent.
- Key slot file permissions. `server/family.js` `saveKeys` writes `keys.json` and its temporary file with `{ mode: 0o600 }`.
- Key masking in event streams and recordings. The bridge masks API keys before broadcasting frames, and `scripts/recording-files.mjs` runs `maskKeys` over logs before building recordings.
- Sub orchestrator ladder scope and restriction modification. `server/orchestrators.js` prevents an orchestrator from changing scopes or removing subs that were created by the owner (`setBy === 'owner'`).
