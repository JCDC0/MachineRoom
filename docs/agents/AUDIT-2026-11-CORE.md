## Scope

This audit reads the pure logic and test infrastructure of MachineRoom:
- `src/model/**`: paths, commands, folder views, hierarchy, parsers, pipeline, log, state, player, source, costs, file index, session recorder.
- `src/harnesses/**`: harness descriptors and line readers for Claude Code, OpenCode, Hermes, AGY, ACP, Codex, Copilot, and MachineRoom.
- `src/briefs/**`: briefs parser, task queues, run helpers, recording builder, and review-lane checks.
- `src/policy/**`: routing policy, profile extraction, and policy proposals.
- `src/assistant/**`: actions, intent parsing, and request dispatching.
- `src/control/**`: control client contract, real client over bridge, and mock client.
- `src/decider/**`: decision models, questions, stats, and baseline evaluation.
- `tests/**`: sample test files across pure logic, mock contracts, timing, fake DOM and event classes, and slow suites.

No production code and no documentation files were edited.

## Efficiency

1. **Folder view indexing in `src/model/folderView.js`**
   - *What it would save*: Replaces the module-global `lastIndex` with a `WeakMap` cache keyed by file list identity. Avoids rebuilding index maps (folders, filesIn, children, fileCount) on unchanged file lists across frame evaluations.
   - *How to measure*: Run `npm run scale-probe -- --files 40000 --folders 4000` and measure `planFolderView` milliseconds per frame.

2. **Hermes parser path resolution in `src/model/parsers/hermes.js`**
   - *What it would save*: Replaces `ctx.files.includes(touched.relative)` with `indexFor(ctx.files).has(...)`. Reduces lookup time from O(N) array scans to O(1) set queries on every tool line. On a 40,000-file project, this eliminates up to 40,000 string comparisons per tool call.
   - *How to measure*: Measure execution time of `hermesFrames` processing in `scripts/scale-probe.mjs`.

3. **Shell command path extraction in `src/model/commands.js`**
   - *What it would save*: `namedSpans` tests all substring slices up to `longest` (up to 200 characters) for every character offset in a command. Splitting command tokens by shell word boundaries first eliminates thousands of redundant `slice` allocations and `Set.has` checks per command.
   - *How to measure*: Benchmark `touchesForCommand` over 1,000 shell commands using `console.time` in `tests/commands.test.js`.

4. **Directory traversal in `src/model/state.js`**
   - *What it would save*: In `applyTouch`, `ancestors(touch.path)` splits and joins paths on every file touch to set `opened = true` on directory entries. If parent directory is already marked opened, traversal can stop early.
   - *How to measure*: Time 200 repeated runs in `tests/soak.test.js` before and after early-exit optimization.

5. **Test server reuse in `tests/projects.test.js`**
   - *What it would save*: Starting an HTTP bridge server takes 100 to 250 ms per instance on Windows. Reusing a single server across the 14 test cases in `projects.test.js` saves 1.5 to 3 seconds of test run time.
   - *How to measure*: Run `npx vitest run tests/projects.test.js` and compare total suite duration.

## What to delete

1. **Dead Paperclip write handlers in `src/control/mock.js`**
   - Delete simulated handlers for `createIssue`, `postComment`, `decideApproval`, `hireAgent`, `updateAgent`, and `setAgentBudget`.
   - Delete helper functions and constants used exclusively by those handlers: `taskDraftProblem`, `hireSummary`, `cleanAgentDraft`, `cleanAgentPatch`, `CANNOT_TAKE_TASKS`, `SAMPLE_APPROVALS`, `SAMPLE_COMMENTS`, and `SAMPLE_ISSUES`.

2. **Tests for removed Paperclip routes**
   - Remove `tests/control-mock-agents.test.js`, `tests/control-mock-briefs.test.js`, and the corresponding write test blocks in `tests/control-mock.test.js`.

3. **Redundant run lifecycle events in `src/model/parsers/copilot.js`**
   - Delete `ensureRunStart` and `ensureRunEnd` in `copilot.js`. Run start and end are managed authoritatively by `pipeline.js` from `heartbeat.run.status` frames.

4. **Unused action confirmation helpers in `src/assistant/actions.js`**
   - `CONFIRMED` is an empty set (`new Set([])`). The `cardFirst` helper and `CARD_SAY` constant are unused by HUD components and can be removed.

## Slowest test files

The slowest test suites by runtime and timeout budget:
1. `tests/soak.test.js` (timeout: 90,000 ms): simulates hundreds of lane runs and reads 500+ log frames through a live bridge loop.
2. `tests/scale-live.test.js` (timeout: 30,000 ms to 90,000 ms): creates a 2,000-file git checkout in temp, runs child processes, and benchmarks CPU and burst memory.
3. `tests/pack-start.test.js` (timeout: 30,000 ms): executes real `npm pack`, extracts the archive with `untar.mjs`, and boots the packaged application in a child Node process.
4. `tests/e2e-room.test.js` (1,153 lines): performs full scene lifecycle, rendering, and interaction tests across Three.js and CSS3D mocks.
5. `tests/control-contract.test.js` (878 lines): initializes a git repository in temp, runs git commands, and validates dozens of bridge routes.
6. `tests/git.test.js` (750+ lines): executes 41 synchronous git child processes for branch, status, log, and worktree assertions.
7. `tests/projects.test.js`: spins up and stops 14 separate HTTP bridge instances.
